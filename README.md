# Zamorak Enrage Tracker

Live site: https://diealivers.github.io/zamorak-enrage-tracker/

## Project Build
Built using [Astro](https://astro.build/), [Flowbite](https://flowbite.com/) and [Tailwind CSS](https://tailwindcss.com/).

## Features
* Enrage tracking of Top 15 solo players
* Personal stats and analytics page
* Calculator for a variety of Zamorak's mechanics
